# ⚡ Turbo Suite APEX

**Turbo Suite APEX** to zaawansowane narzędzie dla systemu Windows stworzone w C#, zaprojektowane z myślą o maksymalizacji wydajności procesora i karty graficznej, redukcji opóźnień (Input-Lag) oraz błyskawicznym zwalnianiu zasobów RAM.

---

### 🚀 Kluczowe Funkcje

* **EXTREME BOOST [E]** – Maksymalny priorytet GPU/CPU dla gier, usunięcie kagańców sieciowych pod niskie opóźnienia i blokada zrzucania jądra do pliku wymiany.
* **HARDWARE BOOST [X]** – Odblokowanie pełnej mocy wszystkich rdzeni CPU (Unpark Cores), wymuszenie planu zasilania *Ultimate Performance* i natywne czyszczenie pamięci.
* **CLEAN CACHE [3]** – Błyskawiczne czyszczenie bufora pamięci DirectX (Shader Cache), plików tymczasowych oraz nieużywanej pamięci RAM.
* **BACKGROUND ENGINE [T]** – Dyskretny moduł działający w tle, dba o czystość RAM i dysku SSD bez obciążania procesora.

---

### 📥 Pobieranie i Uruchomienie

1. Przejdź do sekcji **[Releases](https://github.com/nwmxd322/TurboSuiteApex/releases)** po prawej stronie repozytorium.
2. Pobierz plik `TurboSuiteApex.exe`.
3. Uruchom plik **jako Administrator** (wymagane do wprowadzania zmian w rejestrze i planach zasilania).
